Windows DLNA Media Server

Видео с компьютера — на любом телевизоре в сети

WinDLNA — нативный DLNA/UPnP-сервер для Windows. Установили, указали папки, включили сервер. Телевизор, приставка и медиаплеер сами найдут библиотеку.

Скачать для Windows Как это работает

Windows 10 и 11 · x64 · MSI · без Microsoft Store

Работает из коробки

Self-contained MSI: приложение, WinUI и ffmpeg уже внутри. Не нужен .NET SDK, Store и ручная сборка.

Нативно для Windows

WinUI 3, Mica, трей и автозагрузка. Выглядит и ведёт себя как обычное приложение Windows, а не веб-обёртка.

Простая настройка

Имя сервера, папки с видео, кнопка «Старт». Через минуту библиотека видна DLNA-клиентам в домашней сети.

Возможности

Всё нужное для домашней медиатеки — без облака, подписок и лишних служб.

Несколько папок

Подключайте любые каталоги с видео. Клиенты видят дерево папок и вложенные альбомы.

Автосканирование

Библиотека обновляется каждые 30 секунд. Новые файлы появляются на телевизоре без перезапуска.

Превью роликов

Миниатюры строит встроенный ffmpeg. Кэш хранится локально, в профиле пользователя.

Перекодирование на лету

Если кодек или расширение не подходит телевизору — сервер перекодирует поток. H.264 и H.265 отдаются напрямую.

Статистика клиентов

Видно, кто смотрит: IP, файл, скорость в Мбит/с и идёт ли транскод.

Трей и автозагрузка

Закрытие сворачивает в трей. Можно запускать вместе с Windows в тихом режиме.

Свои интерфейсы

Выберите, на каких сетевых адаптерах анонсировать сервер. VPN и виртуальные карты можно отключить.

Имя и иконка на ТВ

Клиенты видят заданное имя сервера и значок WinDLNA — легко найти среди устройств в сети.

Без прав администратора

HTTP слушает обычный TCP-сокет, без http.sys. После установки сервер запускается от обычного пользователя.

Три шага — и готово

Никаких конфигов, Docker и командной строки.

Установите

Запустите MSI. Программа попадёт в «Программы», ярлык — в меню «Пуск». ffmpeg уже в комплекте.

Добавьте папки

Укажите каталоги с фильмами и сериалами. При необходимости задайте имя сервера и порт.

Включите сервер

Нажмите «Старт» и откройте медиаприложение на телевизоре. WinDLNA появится как DLNA-устройство.
